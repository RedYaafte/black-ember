# Black Ember for Visual Studio Code

Black Ember is a warm, low-glare dark theme with charcoal surfaces, aged
bronze emphasis, and restrained ember highlights.

## Development

Open this directory in Visual Studio Code and press `F5` to launch an Extension
Development Host. Select **Black Ember** from the Color Theme picker.

The theme file is generated from `../palette/black-ember.toml`. After changing
the palette, run:

```sh
python3 ../scripts/generate_themes.py
```

Do not edit `themes/black-ember-color-theme.json` directly.
